# Chainlink Oracle Lending Protocol

## User Request

"Build a simple lending protocol where users deposit ETH as collateral and borrow a stablecoin, using Chainlink for price data."

## Follow-up Answers

- 150% collateralization ratio.
- Anyone can liquidate undercollateralized positions and get a bonus.
- Must work on mainnet fork with real Chainlink price feeds.
- Reject stale price data.
