# ERC-20 Staking dApp

## User Request

"Build me a staking dApp where users deposit an ERC-20 token and earn rewards over time."

## Follow-up Answers

- Users should be able to claim rewards without unstaking.
- Reward rate should be adjustable by the owner.
- Deploy a mock ERC-20 with a faucet so testers can get tokens.
- Keep it to one staking contract + the token.
