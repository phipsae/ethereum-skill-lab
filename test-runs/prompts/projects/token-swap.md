# Token Swap dApp

## User Request

"Build a token swap dApp that lets users swap between tokens using Uniswap V3 on a mainnet fork."

## Follow-up Answers

- Support at least USDC, WETH, and DAI.
- Both direct swaps and multi-hop routes.
- Users can set slippage tolerance.
- Must work on the Anvil fork with real Uniswap contracts.
